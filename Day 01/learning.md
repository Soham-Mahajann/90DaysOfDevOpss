# 1️⃣ What is your understanding of DevOps and Cloud Engineering?

## 🔹 DevOps

The main objective of DevOps is to improve collaboration between development (Dev) and operations (Ops) teams to deliver software faster, more reliably, and with higher quality.Devops is a combination of Developmwnt and Operation.

The main goals of DevOps are:

- Improve collaboration between Development and Operations teams.
- Deliver software faster and more frequently.
- Automate repetitive tasks such as building, testing, and deployment.
- Reduce manual errors through automation.
- Detect and fix issues quickly using continuous feedback.
  
DevOps follows a continuous lifecycle represented by the infinity (∞) loop, where software is continuously planned, developed, tested, released, deployed, monitored, and improved.

---

## ☁️ Cloud Engineering

Cloud Engineering is the process of designing, building, deploying, managing, and maintaining applications and infrastructure on cloud platforms such as AWS, Microsoft Azure, and Google Cloud Platform (GCP).

Instead of purchasing and maintaining:

- Physical Servers
- Hard Drives
- Networking Equipment

We use cloud service providers such as:

- Amazon Web Services (AWS)
- Microsoft Azure
- Google Cloud Platform (GCP)
